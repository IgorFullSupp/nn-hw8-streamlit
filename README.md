# Детектор об'єктів YOLOv8 на Streamlit (ДЗ №8)

Вебзастосунок, який знаходить на фото людей, тварин, транспорт, їжу та предмети побуту
і обводить їх рамками з **українськими назвами класів**.

**Застосунок:** https://nn-hw8-bobukh.streamlit.app

## Модель і класи
- Модель: **YOLOv8** від [Ultralytics](https://docs.ultralytics.com/) (на вибір `yolov8n` — найшвидша, або `yolov8s` — точніша), попередньо навчена на датасеті **COCO**.
- Задача: детекція об'єктів (рамка + клас + упевненість для кожного об'єкта).
- Класи: 80 класів COCO, усі перекладені українською (`classes_uk.py`): людина, собака, кіт, автомобіль, автобус, велосипед, чашка, ноутбук, піца тощо.

## Можливості інтерфейсу
1. Вибір моделі (YOLOv8n / YOLOv8s); назва моделі показана в заголовку.
2. Українські назви класів на рамках, у підсумку й у таблиці.
3. Поріг упевненості та поріг IoU (NMS) — повзунки на бічній панелі.
4. Фільтр: показувати лише вибрані класи.
5. Підсумок: скільки об'єктів кожного класу знайдено.
6. Шкали упевненості для знайдених об'єктів і таблиця з координатами рамок.
7. Кнопка завантаження розміченого фото (PNG).
8. Обробка некоректних файлів: не зображення / пошкоджений файл, надто маленьке фото, автоматичне зменшення надто великого фото, повідомлення, якщо об'єктів не знайдено.

## Приклад роботи
Скриншот працюючого застосунку — у завданні в Classroom.

## Структура
- `app.py` — Streamlit-застосунок
- `classes_uk.py` — українські назви 80 класів COCO
- `requirements.txt` — Python-залежності (PyTorch CPU, Ultralytics, Streamlit)
- `packages.txt` — системні пакети для Streamlit Cloud (OpenCV, шрифт з кирилицею)

## Локальний запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```
