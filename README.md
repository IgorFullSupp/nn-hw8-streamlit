# Класифікатор зображень на Streamlit (ДЗ №8)

Вебзастосунок, який розпізнає, що зображено на фото, за допомогою
попередньо навченої нейронної мережі **MobileNetV2** з [Keras Applications](https://keras.io/api/applications/).

**Застосунок:** <посилання на Streamlit Cloud>

## Модель і класи
- Модель: `tensorflow.keras.applications.MobileNetV2(weights="imagenet")`
- Вхід: зображення 224×224 RGB, нормалізація `mobilenet_v2.preprocess_input`
- Класи: 1000 класів ImageNet (тварини, транспорт, предмети побуту, їжа тощо)

## Можливості інтерфейсу
1. Назва моделі відображається в заголовку та на бічній панелі.
2. Вибір кількості варіантів прогнозу (top-k від 1 до 10).
3. Шкали ймовірностей для кожного варіанта.
4. Поріг упевненості: якщо найкращий варіант нижчий за поріг, застосунок попереджає, що не впевнений.
5. Таблиця ймовірностей (можна вимкнути).
6. Обробка некоректних файлів (не зображення / пошкоджений файл) і попередження для надто малих зображень.
